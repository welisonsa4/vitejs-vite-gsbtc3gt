# Mudanças de UI do RadSaber

## Objetivo
Realizar mudanças visuais pequenas, justificadas e reversíveis, mantendo a identidade visual aprovada.

## Diretrizes
- Azul-marinho profundo, ciano e verde-esmeralda/verde-petróleo.
- Interface moderna, profissional, tecnológica e ligada à Radiologia.
- Priorizar consulta, legibilidade, busca e navegação.
- Preservar componentes e estilos que já funcionam.
- Não redesenhar a aplicação inteira para resolver um detalhe.
- Não adicionar bibliotecas, fontes, ícones ou animações sem justificar necessidade e custo.
- Verificar licenças e origem de imagens.

## Fluxo obrigatório
1. Inspecione os componentes e estilos envolvidos.
2. Liste o que deve permanecer inalterado.
3. Explique a proposta antes de mudanças relevantes.
4. Prefira alterações localizadas; evite substituir arquivos inteiros.
5. Verifique estados hover, foco, ativo, vazio e erro quando aplicável.
6. Considere desktop e celular.
7. Verifique contraste, teclado e semântica.
8. Compare o resultado com a direção visual aprovada.
9. Registre arquivos alterados e limitações de validação.

## Restrições
Não declare a interface aprovada apenas porque compila. Não empilhe regras CSS contraditórias para corrigir uma alteração ruim. Se não puder visualizar a aplicação, diga que a validação visual está pendente.
